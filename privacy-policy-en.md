Privacy Policy - MapSignal
​1. Types of Data Collected
The application accesses and collects the following technical data:
​Location Data: GPS coordinates and mobile network cell positions.
​Phone State: Technical parameters of the mobile network, including signal strength (dBm), cell identifiers (CI, PCI, TAC), signal bandwidth, and frequency bands.
​2. Purpose of Collection (Background Use)
Location data is collected and used to map signal strength and provide accurate network information even when the app is closed or not in use (in the background). This is necessary to allow continuous signal monitoring while the user is using other applications or when the screen is turned off.
​3. Data Storage and Sharing
​Local Processing: All the aforementioned data is processed and stored exclusively in the local memory of the user's device.
​No Sharing: No data is sent to external servers, nor is it shared, sold, or transferred to third parties. The app does not use tracking SDKs or advertising that profiles the user.
​4. Data Control and Uninstallation
The user has full control over their data:
​Historical data can be deleted manually using the "History" function within the application.
​Uninstalling the app will permanently remove all locally stored data.
​5. Contact Information
For any questions or requests, you can contact the developer at the email address provided on the Google Play Store page.
